# Contributor instructions

- Preserve the educational, from-scratch purpose; framework calls must not replace the algorithm
  being taught.
- Never fabricate experimental or benchmark results.
- Add tests with every implementation.
- Use deterministic seeds where possible and record them with results.
- Keep equivalent implementations behaviorally comparable.
- Explain important mathematical and design decisions.
- Do not add large datasets, generated models, build outputs, credentials, or local environments
  to Git.
- Update the implementation-status table in `README.md` when completing a milestone.
